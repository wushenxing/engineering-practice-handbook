# 工程组织与科研实践学习手册

一本面向初学者的独立中文学习手册，讲解公司项目、科研项目及其他工程中的文件组织和工作习惯。

重点是理解文件的用途、来源、生命周期与协作方式，知道为什么这样安排，再按实际需求选择目录和工具。

## 学习范围

- 文件与目录安排，JSON、CSV、源码、配置、模型和日志的不同职责。
- 命名、路径、环境、Git、协作、测试、备份、交接与发布。
- 公司后端、前端、移动端与桌面软件。
- 编译型语言、嵌入式、电子、机械设计与仿真。
- 数据分析、机器学习和计算科研。
- 湿实验、涉及个人数据的研究与社会科学。
- 实验记录、结果复现和论文图表溯源。

## 动手学习

第三章介绍学生成绩统计工程的目录与数据流；第十七章提供完整代码、文件路径、运行命令与预期结果。

该示例只使用 Python 3.10 或更新版本的标准库。随原稿核验的四项测试与两次完整运行已通过；本次排版仅调整长行和缩进展示，三个完整 Python 文件的语法树与原稿一致。

第十九章提供 12 组练习及参考答案，第二十章提供 README、实验记录模板和交付自查表。
